投资小工具 · 拷贝与运行说明（Windows）
=====================================

这个文件夹是一个“自带 Python”的绿色工具，不需要在电脑上安装任何东西。
（图表库已打包在文件夹内，运行时需要联网只是为了拉行情/宏观数据。）

────────────────────────────────────
一、拷到别的电脑（最省事做法）
────────────────────────────────────
1. 把整个【本文件夹】整体复制过去即可（U 盘 / 移动硬盘 / 网络邻居 / 直接复制文件夹都行）。
   ⚠️ 关键：必须连里面的「runtime」子文件夹一起拷！
      runtime 里装好了 Python 和所有依赖（akshare、pandas 等），缺了它就无法运行。
2. 放到目标电脑任意位置：桌面、D 盘、文档里都行，路径带空格也没关系。

────────────────────────────────────
二、怎么运行
────────────────────────────────────
1. 进到文件夹，双击「runmytools.bat」。
2. 会弹出黑色窗口并自动打开浏览器，地址是 http://127.0.0.1:8098
   （如果浏览器没自动开，自己手动输入这个地址也行）
3. 看到网页就能用了。黑色窗口请保持打开——关掉它就停止服务。
4. 用完想退出：直接关掉黑色窗口，或按 Ctrl+C。

────────────────────────────────────
三、换电脑 / 重装系统后
────────────────────────────────────
直接再双击 runmytools.bat 即可，一切照旧，无需安装、无需配置。

────────────────────────────────────
四、后期用 WorkBuddy 继续调试 / 优化
────────────────────────────────────
- 在 WorkBuddy 里“打开文件夹”选中这个目录，就能直接编辑里面的 .py 和 templates/*.html。
- 改完保存后，双击 runmytools.bat 重启（或关掉黑窗口再双击），刷新网页就能看到效果
  （工具已设自动重读模板，一般不用手动硬刷新）。
- 需要新增 Python 第三方库时，在黑窗口或 PowerShell 里运行：
      runtime\python\python.exe -m pip install 包名
- 想换 Flask 端口（默认 8098，若被别的程序占用）：
      用记事本打开 app.py，把顶部「PORT = 8098」改成一个别的数字，重开 runmytools.bat。

────────────────────────────────────
五、备份 / 迁移你的数据
────────────────────────────────────
你的所有个人数据都在这个文件夹内，备份整个文件夹 = 备份全部：
  - config.json        （AI 问答的供应商/密钥等设置）
  - reports/           （你上传的年报 PDF 与提取缓存）
  - peers_cache.json   （同行公司离线缓存）
  - valuation_cache.json / 其它 *.json （各类缓存）
直接把整个文件夹打包，就是完整备份。

────────────────────────────────────
六、常见问题
────────────────────────────────────
Q：双击 runmytools.bat 没反应 / 黑窗口一闪而过？
A：先确认 runtime\python\python.exe 存在、且文件夹完整拷贝过来了；若被杀毒软件拦，把本文件夹加入白名单。
   若双击仍异常，最稳妥的启动方式（100% 有效）：
   按 Win+R → 输入 cmd 回车 → 在黑框里先输入  cd /d "本文件夹路径"  回车，
   再输入  runtime\python\python.exe app.py  回车即可，浏览器会自动打开 http://127.0.0.1:8098

Q：网页打不开 / 提示连不上 8098？
A：先看黑窗口里有没有红色报错。若是“端口被占用”，按上面第四节改 PORT。

Q：图表/数据为空？
A：运行时需要联网拉取数据；请确认电脑能正常上网。
   图表库已本地化，不会因为网络屏蔽 CDN 而画不出图。

（本工具仅限 Windows 使用。）
